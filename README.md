Hướng Dẫn Cài Đặt Nhanh
Google Calendar: Truy cập calendar.google.com
 -> Mục "Lịch khác" chọn (+) -> Chọn "Từ URL" -> Dán link trên -> Nhấn Thêm lịch.
Apple (iPhone / iPad / Mac): Vào Cài đặt -> Lịch -> Tài khoản -> Thêm tài khoản -> Khác -> Thêm lịch đã đăng ký -> Dán link -> Lưu.
Xiaomi CN (HyperOS / MIUI):
Cách 1: Đồng bộ qua tài khoản Google Calendar ở trên (tự động cập nhật).
Cách 2: Tải file .ics về máy -> Mở bằng app Quản lý tập tin -> Mở bằng app Lịch Xiaomi -> Chọn lưu vào Tài khoản cục bộ.
Đặc Điểm Chính
Chuẩn thiên văn UTC+7 theo thuật toán TS. Hồ Ngọc Đức đến năm 2100 (không lệch Tết 2030, 2053).
Tiếng Việt có dấu đầy đủ, 100% không dùng emoji (tránh hoàn toàn lỗi font trên mọi ROM).
Không gây bận lịch (trạng thái Transparent), không ảnh hưởng đến lịch họp hay lịch cá nhân.
